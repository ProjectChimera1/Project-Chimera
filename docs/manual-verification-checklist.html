Project Chimera — Manual Verification Checklist

Single machine · no second laptop required · print & tick as you go
F5 = toggle Play / Edit no key works offline, no LLM needs Ollama/key local model or API key
Launch: open the project in Godot → press F5 to enter Play mode (or run via MCP).  AI features (9 & 10): Esc → Settings → AI Provider → pick Ollama (local), set model → Test connection → Apply & Save. No API key needed with Ollama.

1. AI opponent no key

Do
Load a skirmish map, F5 to Play. Watch the red (P2) side ~2–3 min. Try AiLevel = Hard in Inspector.
Worked?
P2 builds a Barracks <20s after 100 ore → techs to Archery Range → sends attack-waves at your base. HUD sim-hash keeps changing (no freeze).

2. Worker construction no key

Do
In Play, select a worker → command card shows 4 build buttons → click Barracks → click a ground spot.
Worked?
Ore deducts, worker walks to site, green bar fills, building completes, worker returns to gathering.

3. Combat & feedback no key

Do
Move your units into an enemy group (or let a wave arrive).
Worked?
Melee = instant flashes; ranged/siege = visible projectiles; siege hits show red splash; kills trigger a camera shake.

4. Fog of war + minimap no key

Do
Move a unit into unexplored ground. Then click the bottom-right minimap.
Worked?
Black → dim-grey (explored) → clear (visible) as units pass; minimap mirrors fog + blue/red dots; clicking pans the camera.

5. Formations + control groups no key

Do
Box-select a mixed group → Ctrl+1 to assign → move-order somewhere → press 1 to recall.
Worked?
Melee/siege lead the front, ranged/air/workers trail; 1 re-selects the exact group.

6. Terrain editor + undo/redo no key

Do
F5 to Edit → T brush → 1–4 mode → [ ] size → left-drag to sculpt. Then Ctrl+Z / Ctrl+Y.
Worked?
Terrain deforms under the brush; undo/redo steps cleanly with no residue.

7. Win condition + score screen no key

Do
Set a win condition in the Edit-mode panel → Play → eliminate the enemy (or get eliminated).
Worked?
Full-screen VICTORY/DEFEAT card: duration + kills / units-built / ore-mined table. F5 → Edit clears it.

8. Replay (solo lockstep check) no key

Do
Play a match to the end (auto-records to user://replays/*.chmr). Set ReplayPath in Inspector to that file → run.
Worked?
Match replays deterministically from recorded orders — exercises the same lockstep apply path as networked play, solo.

9. LLM triggers needs Ollama/key

Do
Edit → L panel. No-key path: hand-add a match_start → add_resources trigger to a scenario JSON, reload, Play. With model: type a description → Generate → Accept.
Worked?
Inline: ore jumps on tick 1. Generated: valid JSON preview appears and Accept adds it to the list.

10. AI map generator needs Ollama/key

Do
Edit → M panel → type a map brief → Generate ✦ → Load (no save).
Worked?
Preview shows name/bounds/counts; scene reloads into the map; validator rejects out-of-bounds coords, ore closer than 15u, or >6 units/faction.
