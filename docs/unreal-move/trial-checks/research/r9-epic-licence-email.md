Hello,

I am a solo developer making Project Chimera, a real-time strategy game built in Unreal Engine 5. Like Warcraft III, it includes an
in-game map editor: players build maps and custom games that are played only inside Chimera. Before I decide which assets the editor
may offer, I would like your guidance on three licences.

How the editor works:
- Players place assets from the game's own built-in library (ground textures, grass, trees, rocks, units, effects) onto a map.
- A saved map is our own data file. It refers to library assets by ID and contains none of their meshes, textures or other files.
- The asset files ship only inside the game's packaged files. The editor cannot export or extract meshes or textures, and maps cannot
  be opened outside Chimera.
- Players can share their maps with other Chimera players. A shared map still contains only references.

My questions:

1. **Fab Standard License content** (Quixel Megascans and Megaplants, and the Paragon packs, which Fab now lists under the Personal and
   Professional tiers). Section 6(b)(iii) of the Fab EULA bars letting third parties incorporate Content into their own projects, "for
   example ... world- or level-editing tools or templates or other modeling tools that allow works to be exported", and Section 4(c)
   requires restricting end users from extracting Content. May players place this content in maps made with an editor that works as
   described above? If not, is there a licence that would allow it?

2. **Unreal Engine sample content**, for example the sample assets that ship with the Procedural Vegetation Editor plugin in Unreal
   Engine 5.8. Under the Unreal Engine EULA, does placing these assets in maps made with an in-game editor count as end users making
   "permitted uses of the Product"?

3. **Content Epic provided as UE-Only Content before Fab launched** (for example, Paragon packs from the Unreal Engine Marketplace, and
   Megascans claimed through Quixel Bridge on the Unreal Engine plan). Section 5(c)(iii) of the Epic Content License says its editor
   restriction "does not apply to UE-Only Content". Does that exception cover such copies, so that they may be offered in an editor like
   ours? And do they keep those terms now that the same items are distributed through Fab?

I am glad to share more detail about the editor if that would help. Thank you for your time.
