## 2. What Went Well

1. **The determinism fence held while an entire combat engine was built on top of it.** Four folds, each deliberate and re-baselined; every no-fold story (2.7, 2.8, 2.9a/b, 2.10, 2.11, 2.13) kept all goldens byte-identical. Epic 1's #1 ship risk stayed retired the whole way. The enabler was codifying the **checksum-fold-timing rule** as a standing heuristic (fold only when a new array first becomes mutable mid-match) — so the "should this fold?" question stopped being re-asked every story and became mechanical.

2. **The 3-layer review kept catching ship-blockers Tier-1 could never see.** Headline saves: 2.9b's `StartCrystal`/`CanonicalModelHash` gap (two clients would hash-*equal* at the lobby handshake then desync from tick 1 — fixed in-review via the 2→3 fold); 2.8's three `(int)enum`-indexed array **crash sites** (`NavObstacleManager.TYPE_SIZE[4]`, `EntityPlacer.BUILDING_COSTS[4]`, an invisible-render `TYPE_COUNT`), all Godot-side and invisible to the headless gate; 2.6's aura-permanent + `period_count=0` validator hole; 2.13's Blind Hunter catching the Neutral-building auto-attack the Auditor missed.

3. **Story splitting stayed disciplined.** Four oversized originals split into shippable, independently-golden-gated halves (the same pattern that worked 8× in Epic 1). No slice shipped half-built.

4. **The "recommended-default decision" pattern matured into real authorial control.** Stories surfaced decisions *with* a baked recommendation plus alternatives; Alec resolved them crisply, several as deliberate scope *expansions* (2.9a's real-projectile-vs-building + reserved-TargetFilter evaluation; 2.13's generation-armored packed refs + first-class `cost_health`). Fast without ceding the design call.

5. **Epic 1's action items paid off — visibly.** **A2** (single-mapper SoA rule + `ApplyUnitDefinitionGuardTest`) was load-bearing every time Epic 2 added a per-unit array (Energy, FeedbackProfile, AttackDomain, TagsOf) — the 1.12/1.13 spawn-path defect class did **not** recur. **A3** (prove every gate has teeth) held: reviews demanded RED-proven negative controls throughout (`ChangedStartCrystal_HashDiffers`, `AiBelowThresholdRazeTests`, the 2.6 teeth).

6. **Content-validator rigor deepened.** 2.6 established that validators must check a granted modifier's *behavioral* params (duration / stacking / `period_count`), not just node shape — or you ship validated-but-misbehaving content. A durable quality lesson for a data-driven platform.

## 3. What Was Hard — Patterns & Growth Areas

1. **The physical-gesture proof gap recurred every wired story.** RMB-attack-a-building, Shift+RMB waypoint chains, rally-drag, worker select→cast, air skirmish — all consistently **parked as manual-QA** because 3D picking is fragile, with behavior proven instead by goldens + loopback + code inspection + a live `/godot-verify` boot. Individually justified (precedent since 1.9b), but it's now an accumulated backlog of gestures no human has clicked. → **Decision D-1 (routes to Epic 10/11).**

2. **"New closed-set member not propagated to every indexed site" is Epic 2's version of Epic 1's spawn-path bug.** 2.8's `BuildingType.Aviary` had to touch both `switch`es *and* every `(int)enum`-indexed array — and a switch-grep missed the arrays, two of which crash past the Tier-1 gate. Same *shape* as the 1.12/1.13 class A2 fixed, just on enums instead of spawn paths. Codified to memory; not yet structurally guarded. → **Optional action item A6.**

3. **Recurring deferred content-validator gaps.** 2.9b surfaced (again) that unit costs have no lower-bound guard (`cost_crystal: -30` *adds* crystal each train) and start-resources ≥ ~32768 overflow the 16.16 `Fixed` type — the *same* ceiling first logged in 1.3b. Shipped content is safe; creator-authored data isn't. It kept getting deferred because there was no creator-facing editor to attach it to. → **Decision D-2 (folds into Story 3.4).**

4. **Review-model posture drifted.** Most stories used a fresh-context different-LLM review; 2.13 deliberately kept *same-model* (Opus 4.8) with 3 layers + an independent determinism verdict. Both defensible, but implicit rather than decided. → **Decision D-3 (per-story discretion).**

5. **Epic 2 became the debt-paydown epic.** 2.13 alone closed items deferred from as far back as the 2026-06-09 AI investigation (arrival-hover deadlock, AttackMove-building acquisition) plus 2.10's Spike-0HP and the rally-replication desync. Good that it got paid — but it's why the epic grew 11 → 17. The AI is still **float** (2.13's raze path included), which is fine today (AI doesn't run in lockstep) but means the deferred `float→Fixed` conversion (now Story 10.13) carries more behavior each combat epic.
