# Trial kit (S4)

Shared tools for the three Unreal trial checks (EXECUTION.md 2.1 S4, 2.2, 2.3). Tests: `python -m pytest tools/unreal-trial/tests -q`.

| Tool | Use |
|---|---|
| `preflight.ps1 [-Quiet]` | Prints `DESKTOP OK 1920x1080 @96` (exit 0) or `DESKTOP NOT 1920x1080@100% ...` (exit 1); records `PARSEC running/absent`. DPI is AppliedDPI, then LogPixels, then GetDeviceCaps; if none can be read it prints `@?` and exits 1. `-Quiet` also samples 10 s: no `dotnet/ilc/cl/link/MSBuild/testhost/Godot*/ffmpeg/ShaderCompileWorker` process above 5% of a core and none of them born during the window, total CPU below 10%, prints the `MsMpEng` CPU; exit 2 when busy (1 wins when the desktop also fails). Windows PowerShell 5.1 compatible. Run wrappers call it before taking the lock; `ue_lock.sh --measure` calls it with `-Quiet`. If GetSystemTimes fails it prints `QUIET NOT total=?` and exits 2 (fail closed). Test knobs: `-SampleSeconds`, `-ProcLimitPct`, `-TotalLimitPct`, `-TestFailSystemTimes`. |
| `logscan.py LOG...` | One Unreal log rule set (C4). **Calibrated on 9 `UnrealEditor.exe -game` logs** (all `game_*`/`warm_*` in `P/LookTest/logs` scan clean); **packaged logs are UNVERIFIED** until C11's first packaged run. The `Failed to load` rule is stricter than C4 (which fails only `Failed to load '/` and game mode), so any allowance added for packaged logs needs an evidence line, as the four profiler DLLs have. Allows exactly the four profiler DLL probes (aqProf, VtuneApi, VtuneApi32e, WinPixGpuCapturer); every other line containing `Failed to load` fails, as do `LogChimera*: Error`, RealtimeMesh Error/Warning, `Ensure condition failed`, any `Fatal` (C's rule), `Unhandled Exception`, `Assertion failed`, `Critical error`, B T9's `LogLinker`/`LogStreaming` Error/Warning and `LogUObjectGlobals: Warning: Failed to find`, `UpdateTextureRegions called for`, `SHOT TIMEOUT/MISSING/NO CALLBACK`. Editor and commandlet logs: `--profile editor`, which also allows `Wintab32.dll` and two known engine ensures by exact condition and file (see `EDITOR_ALLOW`). `--extra-fail REGEX`, `--ignore REGEX`. |
| `secret_scan.py PATH...` | Exit 1 when a line assigns a value to a SecurityToken name or a name ending in key, token, secret, password (any case). Two matches: a name at line start (optional `export`/`const`/`ENV`, `$`/`$env:`, ini `+-.!`, YAML `- `, JSON quotes; `=` or `:`, never `==`/`=>`), and anywhere in a line a secret-like name, optional type annotation, `=`/`:` and a quoted literal of 8+ chars (also `TEXT("...")`, `L"..."`, `@"..."`), which catches C#/C++ declarations, PowerShell variables, env-prefixed commands and dict literals. Strong names (api, secret, password, access, private, auth, credential, encryption, signing, bearer, SecurityToken) fail on any real value; other `*key`/`*token` names used as data keys (`"asset_key": "sanguine_furnace"`) fail only on a secret-looking value (sk-/ghp_/AKIA/eyJ prefix, or 16+ chars with digits and letters). Placeholders, escapes, code expressions, type names, URLs (weak names), NAME_None-style literals and PascalCase input keys are ignored. Reads UTF-8 and UTF-16 (BOM or BOM-less, as PowerShell 5.1 `>` writes); a text-extension file that still looks binary prints `SECRET_SCAN SKIP <file> (binary)`. `secret-scan: allow` lines are skipped and counted (`SECRET_SCAN ALLOWED n`). Values are masked. Skips Binaries, Intermediate, Saved, .git and binary files. Passes on every `tools/unreal-*` tree and `godot/`; on all of `U` it reports exactly one line, `P/Config/DefaultEngine.ini:92` (correct). |
| `evidence.py` | `add` (copy or `--register`, name rule, sha256, size, pixel size into `EV/<check>/manifest.json`), `phone` (JPG <= 1600 px, <= 1 MB), `sheet`, `scorecard` (JSON spec; `TRIAL PASS` only with exactly one entry each for (a), (b), (c), all PASS, else PARTIAL/INCOMPLETE/FAIL), `sent`, `check`. `check`: every manifest entry exists with its sha256; every file git tracks or would add under EV (tracked plus untracked, not ignored) obeys the 2.3 size/type policy, is not a (b) image, and is a committed manifest entry; EV root holds only README.md, trial-scorecard.jpg, lock-usage.csv. Every file on disk under `EV/<check>` (git-ignored or not) must be referenced by a manifest row: an unlisted (b) image fails, other unlisted files print `EVIDENCE NOTE`. Committed rows store `path` relative to EV (`a/<file>`) and are read from `EV/<check>/<file>`, so a clone elsewhere checks clean; registered rows keep the absolute working-folder path. Outside a git work tree it checks every file on disk and says so. `--ev DIR` overrides the evidence dir. |
